安装后首次启动会让你填服务器地址（例如本页的域名，或局域网 http://192.168.x.x:8080）。 也可以「添加到主屏幕」用 PWA 方式安装：Chrome 菜单 → 添加到主屏幕，一样全屏横屏。

安装步骤

  1. 点上面的「下载 APK」，浏览器会保存安装包。
  2. 打开文件管理器点击 APK，允许「安装未知应用」。
  3. 启动 Saltline，填入服务器地址，进入大厅。
  4. 大厅里可以：看公告、加好友、组队、买皮肤、看排行榜、打单挑。

玩法

  1. 搜打撤：搜箱拿战利品，带价值活着走到撤离点。死了身上的东西全没。
  2. 大战场：两队抢三个点，票数先掉光的一方输，可以无限复活。
  3. 单挑：一对一先赢 3 回合，段位分按胜负结算。
  4. 中继破坏：切断三座上行中继，无人机和机器狗会来找你。
触屏：左摇杆移动，右半屏拖动转视角，右摇杆也能转；开火/瞄准/换弹/蹲/跳/交互在右下角；V 键（或「舞蹈」按钮）打开表情轮盘。

自建服务器（可选）

把本仓库拷到任意有 Node.js 18+ 的机器：
  1. npm install
  2. npm start（默认 8080 端口，可用 PORT=9000 npm start）
  3. 后台地址 /admin，密码用 ADMIN_PASSWORD 环境变量指定
  4. 公网：TUNNEL=cloudflared npm start 会顺手拉起临时公网地址，或 npm run tunnel
